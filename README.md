# Criteo Frozen Benchmark

Reproducible, exploratory research on delayed conversion feedback using the public Criteo attribution dataset. No private research or credentials are included.

The GitHub Actions CPU workflow runs only the development portion. It verifies the official dataset's SHA-256 before benchmarking and does not publish the original dataset.

**Scientific status:** preflight verified; real-data superiority not established. Dataset source: https://huggingface.co/datasets/criteo/criteo-attribution-dataset (CC BY-NC-SA 4.0).
